# English Maturita Quiz

Jednoduchá responzivní webová aplikace pro procvičování angličtiny k maturitě.

## GitHub Pages

1. Nahraj všechny soubory z tohoto projektu do GitHub repository.
2. Otevři **Settings → Pages**.
3. Zvol **Deploy from a branch**.
4. Vyber `main` a `/ (root)` a ulož.

## Funkce

- 10 náhodně vybraných otázek
- 4 možnosti odpovědi
- kontrola odpovědi a vysvětlení
- skóre a úspěšnost
- progress bar
- restart kvízu
- responzivní design
- bez API klíčů a backendu
